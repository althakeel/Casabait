# Email Template Previews

Static HTML previews of the contact form email templates.

## View locally

Open any `.html` file in this folder in your browser:

- `internal-notification.html` — team inbox notification
- `auto-reply-en.html` — English confirmation to the submitter
- `auto-reply-ar.html` — Arabic confirmation to the submitter

## Regenerate after template changes

```bash
npm run email:preview
```
